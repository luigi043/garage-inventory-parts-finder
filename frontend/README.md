# Garage Inventory And Parts Finder Frontend

Portfolio-ready React + TypeScript interface for the 5-day MVP.

## Run

~~~powershell
npm install
npm run dev
~~~

## Build

~~~powershell
npm run build
~~~

## API

Set the API base URL when the backend is not running on the default port:

~~~text
VITE_API_BASE_URL=http://localhost:5000
~~~

## Screens

- Login and registration.
- Dashboard.
- Part records workspace.
- Operations advanced feature panel.
