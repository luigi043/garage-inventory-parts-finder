# Portfolio Summary

## Project

Garage Inventory And Parts Finder

## Why It Matters

Build a garage inventory platform for tracking parts, tools, suppliers, compatibility, VIN metadata, and stock location.

## Hiring Signals

- Full-stack architecture with ASP.NET Core and React.
- JWT auth with refresh-token flow.
- EF Core persistence and PostgreSQL setup.
- Protected API workflows.
- Application-layer business logic.
- Automated backend tests.
- Production frontend build.
- Deployment-ready documentation.

## Advanced Feature

Compatibility checker for vehicles, parts, and supplier options.

## Demo Path

Create a Part, edit it, then open Operations to show the advanced feature readiness panel.
